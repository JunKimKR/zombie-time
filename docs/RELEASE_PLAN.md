# 1.1 출시 준비와 수익화

## 이번 버전
- 캐릭터 탭 반응, 부드러운 좀비화, 정적 미리보기의 불필요한 무한 애니메이션 제거.
- 5/15/25분 자율 휴식 타이머. 화면 잠금/프로세스 종료 뒤에도 같은 부팅 세션에서 복원. 재부팅하면 취소. 앱을 다시 열면 완료 정산하며 완료 알림은 제공하지 않음.
- 무료 씨앗(5분당 1개), 연속 휴식일, 누적 시간, 1/5/20회 배지, 복숭아/숲/달빛 배경.
- 씨앗과 구매 통화는 별개. 현재 네트워크·실제 결제·광고 SDK 없음. SNS 기록을 지우거나 줄이지 않음.
- API 36, AGP 8.10.1, Gradle 8.11.1. 시스템 바 안전 영역 적용.
- CI: 단위 테스트, lint, 설치 가능한 debug APK, 서명 전 release AAB. main 빌드 성공 시 v1.2.0-preview.1 테스트 릴리스를 한 번 게시. 기존 태그와 파일은 덮어쓰지 않음.

## Play 제출 전 남은 작업
1. Play Console 앱 등록, applicationId 소유 확인, 업로드 키 생성 및 Play App Signing 구성. AAB는 현재 미서명이며 그대로 제출할 수 없음. 기존 debug 설치와 production 서명은 호환되지 않으므로 테스트 데이터 보존에 주의.
2. 개인정보처리방침의 공개 URL 및 개발자 연락처, 데이터 보안/콘텐츠 등급/타깃층/사용 정보 접근 고지 작성. 백업을 끄므로 삭제·기기 변경 시 로컬 기록과 무료 보상은 복구되지 않음.
3. specialUse 포그라운드 서비스의 Play Console 선언/심사 자료 준비. 상시 알림, 사용자 시작·종료, 배터리 동작을 실제 기기에서 확인.
4. API 26/33/35/36 및 삼성 기기에서 권한 거부·철회, 알림, 재부팅, 자정, 화면 잠금, 큰 글꼴, 제스처 탐색, 공유, 멀티윈도우를 점검. UsageEvents 집계의 제조사별 정확도도 확인.
5. 계정에 적용되는 내부/비공개 테스트 요건 확인 후 단계적으로 출시.

## 유료화 권장 범위
초기판은 사용시간 측정·회복·기본 통계를 무료로 제공. 이후 캐릭터 스킨/테마 묶음과 심화 리포트를 유료 후보로 검증한다. 사용시간을 돈으로 지우거나 경고를 피하게 만들지 않는다.

유료 포인트를 도입할 경우 현재 RecoveryState.seeds를 재사용하지 않는다. Google Play Billing 상품 ID와 서버 원장을 별도로 두고, 서버에서 purchaseToken 검증·중복 지급 방지·승인/소비·취소/환불·보류 구매·복원 처리를 구현한다. 가격은 Play 상품 정보에서 받아 표시하고, 상품이 없거나 연결에 실패하면 결제 버튼을 숨기거나 재시도를 제공한다. 실제 지급은 검증된 PURCHASED 상태에만 수행한다.

- 5분 타이머 시작 → 앱 종료 → 재실행 → 남은 시간 유지 → 완료 시 씨앗 1개, 1회만 지급.
- 타이머 취소·재부팅 → 보상 없음. 날짜 변경은 경과 시간 계산에 영향 없음.
- 씨앗 부족 시 배경 잠금; 충분하면 정확히 차감; 보유 배경 재선택 무료.
- 홈/쉼터 배경 동기화, 앱 재실행 후 유지. 같은 날 여러 회 완료해도 연속일 증가 없음.
- 큰 글꼴과 작은 화면에서 모든 버튼까지 스크롤 가능. 시스템 애니메이션 0 설정에서 사용 가능.
