# 좀비타임 1.2 테스트판

Android 8.0 이상에서 `zombie-time-1.2-preview.apk`를 내려받아 설치하세요.
휴대폰에서 파일을 열고, 요청되면 해당 브라우저/파일 앱의 '알 수 없는 앱 설치'를 허용하세요.

앱 이름은 **좀비타임 테스트**입니다. 기존 좀비타임과 별도 설치되며 기존 앱과 데이터가 덮어써지지 않습니다.
처음 실행하면 테스트 앱에 사용 정보 접근과 알림 권한을 허용해 주세요.

## 먼저 확인할 기능
1. 홈의 캐릭터를 3번 눌러 웃음·놀람·윙크, 점프·팔 흔들기, 말풍선과 짧은 효과음 확인.
   - 사각형 눌림 효과가 없는지, 소리 끄기/무음 모드에서 조용한지 확인.
   - 홈·기록 탭의 인스타그램/스레드/페이스북/유튜브 실제 앱 로고 확인.
2. 쉼터에서 5분 타이머 시작 → 화면 잠금 → 다시 열기 → 완료 후 씨앗 1개 지급 확인.
3. 타이머 취소 시 보상 없음, 완료 후 재실행해도 중복 지급 없음 확인.
4. 씨앗 6개로 초록 숲 해제 → 홈 배경 변경 → 재실행 후 유지 확인.
5. 앱별 사용시간, 주간 통계, 알림, 브리핑 카드 공유 확인.

자율 휴식 타이머이며 다른 앱을 차단하거나 사용 여부를 검사하지 않습니다.
씨앗은 무료 로컬 보상입니다. 실제 결제는 없으며 Play Store 배포본이 아닙니다.
테스트용 debug 서명 APK이며 실기기 검증 중입니다. 향후 테스트판의 서명키가 달라지면 재설치가 필요할 수 있고, 삭제하면 테스트 앱의 기록과 보상이 사라집니다.

자동 테스트 5개·Android lint·APK/AAB 빌드가 모두 성공한 경우에만 게시됩니다.
